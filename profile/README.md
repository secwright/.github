## Secwright

An open-weight AI model trained to do hands-on security engineering. It finds, fixes and hardens security issues in your own code and infrastructure, and it's fast enough to run on your own hardware.

**Status: design phase.** Start with the plan: [secwright/secwright → docs/PLAN.md](https://github.com/secwright/secwright/blob/main/docs/PLAN.md)

Defensive use only: see our [security policy](https://github.com/secwright/secwright/blob/main/SECURITY.md).
